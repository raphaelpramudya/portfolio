Interactive Smart Waste Sorting

An interactive educational poster designed to teach children about proper waste management and waste categorization. Served as the Hardware Component Developer and Programmer, developing the interactive components and coding the system to support an engaging learning experience.

Role
Hardware & Program Developer
Tools
Arduino C & C++
Duration
2 Weeks
Category
Interactive Media
Live Demo

Overview

Developed an interactive educational poster designed to introduce young children to proper waste management and waste separation. The project combined physical interaction, electronic components, and educational content to create a more engaging learning experience.

Goal

The goal was to make waste separation easier and more engaging for children by transforming conventional educational material into an interactive learning medium. The project aimed to encourage children to recognize different types of waste and understand the importance of sorting waste correctly.

Process

  1. Concept

    Creating idea and drawing prototypes of the components used

  2. Execution

    performing the installation and mounting of electrical components.

  3. Demonstration

    Presented and demonstrated the poster's interactive functions.

Result

Designed and implemented the mechanical and electrical systems that enabled the poster’s interactive features. This project strengthened my skills in integrating mechanical mechanisms with electronic components while developing an interactive educational medium for children
