PENSTour - Navigation and Virtual Tour of EEPIS

A Mixed Reality virtual tour application for PENS, developed using Unity to provide an immersive way to explore the campus. Designed the UI panel and initial interface, focusing on creating an intuitive and engaging experience for users.

Role
UI Designer
Tools
Figma & Unity
Duration
6 Weeks
Category
Immersive Technology

Overview

Designed the user interface for PENSTour, a campus navigation application developed with Unity to help users explore and navigate the PENS campus. The project combines interactive navigation with an immersive digital experience, providing users with accessible information about campus locations.

Goal

The goal was to create an intuitive and visually clear interface that allows users to navigate the campus easily. The UI was designed to support the application's navigation features while maintaining a consistent and engaging visual experience.

Result

Designed and implemented the UI panels and interface elements for the PENSTour application, ensuring that the interface was functional, accessible, and visually consistent with the application's concept. This project strengthened my skills in UI/UX design, Unity-based interface development, and designing interfaces for immersive applications.
