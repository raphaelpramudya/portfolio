SIMPUYER - Simulation of Making Powdered Medicine

A WebXR-based VR simulation for learning the process of powder medication preparation, featuring an interactive UI designed with WebGL. Developed the UI panel to support an intuitive and immersive learning experience within the VR environment.

Role
UI Designer
Tools
WebGL & WebXR
Duration
5 Weeks
Category
Immersive Technology
Live Demo Source

Overview

Designed the user interface for a Virtual Reality application built with WebXR, focusing on creating an intuitive interface that can be accessed and interacted with within a VR environment. The project explored the use of web-based technologies to deliver an immersive application experience

Goal

The goal was to develop a clear and accessible UI that allows users to interact with the application naturally in a virtual environment. The interface needed to remain easy to understand while adapting conventional UI principles to the spatial requirements of VR.

Result

Designed and implemented the UI elements and panels for the WebXR-based VR application, focusing on usability, visual consistency, and interaction within the virtual environment. This project strengthened my understanding of VR interface design, WebXR, spatial UI, and designing interactive experiences for immersive technologies.
