CodeLab - Web for Learning Python

A web-based learning platform designed to help beginners learn Python through interactive lessons and hands-on practice. The platform features a live coding environment and a community page to encourage collaboration and knowledge sharing.

Role
Front-end Developer
Tools
HTML, CSS & JavaScript
Duration
2 Weeks
Category
Web Development

Overview

Designed a web-based learning platform for beginners to learn Python through interactive lessons and hands-on practice. The platform features a live coding environment and a community space for discussion and knowledge sharing.

Goal

The goal was to make learning Python more accessible and engaging by combining structured learning materials with practical coding exercises. The community feature was also designed to encourage learners to discuss problems, share knowledge, and learn collaboratively.

Result

Designed and developed the website interface and its key features, including the live coding environment and community discussion space. This project strengthened my skills in web interface design, interactive learning experiences, and designing platforms that support collaborative education.
