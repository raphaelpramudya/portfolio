LangKita - Mobile Apps UI Design

A mobile application interface designed to help small and medium-sized businesses (SMEs) adopt and manage digital transformation. Focused on creating an intuitive and accessible UI to support business owners in integrating digital tools into their daily operations.

Role
UI Designer
Tools
Figma
Duration
2 Weeks
Category
UI/UX

Overview

Designed the web and mobile interfaces for a digital platform that helps small and medium-sized businesses (SMEs) adopt digital tools with guidance from mentors. The platform consists of two interfaces: one for SME clients and another for mentors.

Goal

The goal was to create an accessible platform that helps SMEs navigate their digital transformation while enabling mentors to provide guidance, monitor progress, and support their clients effectively.

Result

Designed the UI for both client and mentor platforms, creating clear user flows and interfaces tailored to their respective needs. This project strengthened my skills in UI/UX design, responsive interface design, and designing digital platforms for different user roles.
