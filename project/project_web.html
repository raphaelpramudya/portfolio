RUNZ - Web UI Design

A website designed for a running and jogging community, providing an engaging platform for members to connect, share activities, and stay involved with the community. Focused on creating a clean and user-friendly interface that supports community interaction.

Role
UI Designer
Tools
Figma
Duration
1 Weeks
Category
UI/UX

Overview

Designed a website interface for a running community using Figma, focusing on creating a clean and engaging digital platform for runners. The design includes key interface elements and layouts to support community activities and user interaction.

Goal

The goal was to create an intuitive and visually appealing website that makes it easy for community members to access information, discover activities, and stay connected with other runners.

Result

Designed the website interface and visual layout in Figma, focusing on usability, consistency, and user experience. This project strengthened my skills in UI design, layout composition, and creating digital interfaces for community-based platforms.
